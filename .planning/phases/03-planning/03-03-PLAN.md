<objective>
Complete the `/planejamento` slice with the weekly tracking surface and wire the dashboard: the 4 weekly cards ("Gastos semanais") with the automatic "Gastei R$" (summed from real CASA transactions in each week's date range) plus a persisted manual override and "Recalcular"; the derivation of registered contas fixas into the plan's "Contas fixas" group at render time (PLAN-06/D-05); and the Casa dashboard "Planejado"/"Folga" cards finally showing the real plan total instead of "--".

Purpose: PLAN-04 and PLAN-06 close the loop between the plan and the user's real spending. The auto-"Gastei" reuses the shared `weeks.ts` range logic (Plan 01) so the weekly cards and the dashboard chart agree. The override is persisted nullable-by-row (WeeklySpend) so new transactions keep updating the auto value unless the user fixes it by hand (Pitfall 4). Fixed accounts are derived, never duplicated into PlanItem (D-05), keeping one source of truth.

Output: Weekly cards + inline Gastei editor + WeeklySpend override actions, fixedAccountsAsRows derivation, getPlanTotal, and dashboard Planejado/Folga wiring.
</objective>
