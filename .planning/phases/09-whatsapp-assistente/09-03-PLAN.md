<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mensagem de resposta (multi-turno) → pendência no Postgres | A resposta do usuário completa uma ação parcial; a pendência carrega dados financeiros parciais |
| Setup externo (Vercel env / instância Evolution / linha allowlist) → runtime | Credenciais e a identidade do canal são definidas fora do git |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-08 | Tampering | Pendência "sequestrando" uma mensagem nova e solta | mitigate | TTL (`expiresAt`) curto; `findPendingAction` só considera pendência com `expiresAt > now`; expirada é ignorada/limpa — a mensagem vira nova extração |
| T-09-09 | Information Disclosure | `partial` da pendência com dado financeiro parcial | mitigate | Escopada por `phone` (já resolvido para o userId confiável); não logar o `partial`; TTL limita a janela de exposição; sem exposição a número fora da allowlist (barrado antes, no 09-02) |
| T-09-10 | Elevation of Privilege | Criar categoria nova por chat (fora do escopo D-04) | mitigate | `resolveCategoria` só casa com categorias EXISTENTES do destino; nenhuma correspondência → pergunta oferecendo as existentes; nunca `createCategoryService` a partir do webhook |
| T-09-11 | Information Disclosure | Segredo na query string da URL do webhook em logs da VPS | accept | A Evolution não assina HMAC por padrão; o segredo na query é a opção que sempre funciona; comparado com `timingSafeEqual`; risco residual (log da VPS) aceito — alternativa via header `x-webhook-secret` fica disponível no `verifyWebhookSecret` se o Thaylan preferir |
| T-09-12 | Spoofing | Body do sendText errado (version mismatch) → falha silenciosa de resposta | mitigate | Confirmar o shape contra a instância real (checkpoint, curl de teste); ponto único em `evolution.ts` para trocar v2↔v1 |
| T-09-13 | Compliance (LGPD) | Dado financeiro trafegando por WhatsApp sem consentimento | mitigate | `WhatsappContact.consentAt` registra o consentimento com data (§5 do design); só número com contato ativo transaciona |
</threat_model>
