    **schema.ts** — Zod schemas only:
    - ceilingUpdateSchema: z.object({ month: z.string().regex(/^\d{4}-\d{2}$/, 'Formato inválido'), ceilingCents: z.number().int().positive('Teto deve ser maior que zero') }).
    - Export CeilingUpdateData as z.infer.

    **service.ts** — pure TypeScript, no 'use server', imports prisma from '@/lib/prisma':
    - getOrCreateMonthlyBudget(userId: string, month: string): implements D-04 fallback logic.
      1. Try prisma.monthlyBudget.findUnique({ where: { userId_month: { userId, month } } }).
      2. If found, return it.
      3. If not found: prisma.monthlyBudget.findFirst({ where: { userId, month: { lt: month } }, orderBy: { month: 'desc' } }) to find the most recent previous month's budget.
      4. Set ceilingCents = previous?.ceilingCents ?? 300_000 (R$ 3.000,00 default per D-04).
      5. Return prisma.monthlyBudget.upsert({ where: { userId_month: { userId, month } }, update: {}, create: { userId, month, ceilingCents } }).
    - upsertMonthlyBudget(userId: string, month: string, ceilingCents: number): prisma.monthlyBudget.upsert({ where: { userId_month: { userId, month } }, update: { ceilingCents }, create: { userId, month, ceilingCents } }). Used when user explicitly edits the ceiling.
    - getTotalSpent(userId: string, month: string): parse month "YYYY-MM" to year/monthNum. Build date range. prisma.transaction.aggregate({ _sum: { amountCents: true }, where: { userId, account: 'CASA', type: 'SAIDA', date: { gte: start, lte: end } } }). Return _sum.amountCents ?? 0.
    - getCategorySpending(userId: string, month: string): parse month to date range. prisma.transaction.groupBy({ by: ['categoryId'], where: { userId, account: 'CASA', type: 'SAIDA', date: { gte: start, lte: end } }, _sum: { amountCents: true } }). Then enrich with category names: prisma.category.findMany({ where: { id: { in: categoryIds } } }). Return array of { categoryId, name, totalCents } sorted by totalCents desc.
    - getWeeklySpending(userId: string, month: string): parse month to date range. prisma.transaction.findMany({ where: { userId, account: 'CASA', type: 'SAIDA', date: { gte: start, lte: end } }, select: { date: true, amountCents: true } }). Map each transaction to a week bucket using getDate(): day <= 7 → index 0, day <= 14 → index 1, day <= 21 → index 2, else → index 3. Return array [{ week: 'Sem 1', totalCents: N }, { week: 'Sem 2', totalCents: N }, { week: 'Sem 3', totalCents: N }, { week: 'Sem 4', totalCents: N }].

    **loader.ts** — thin wrapper that orchestrates service calls for the page:
    - loadDashboardData(userId: string, month: string): calls Promise.all([getOrCreateMonthlyBudget, getTotalSpent, getCategorySpending, getWeeklySpending]) and returns all four results as a named object { budget, totalSpentCents, categorySpending, weeklySpending }.

    **actions.ts** — 'use server' thin actions:
    - upsertMonthlyBudgetAction(_prev: unknown, data: CeilingUpdateData): userId from session (createSupabaseServerClient never from form input), parse with ceilingUpdateSchema.safeParse, call upsertMonthlyBudget(userId, data.month, data.ceilingCents), revalidatePath('/visao-geral'), return { success: true } or { success: false, error }.
    - Error message on network failure: "Não foi possível salvar. Verifique sua conexão e tente novamente."
