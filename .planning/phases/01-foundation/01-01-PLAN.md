## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | middleware.ts — session verification | mitigate | Usar getUser() em vez de getSession() — getUser() valida JWT com o servidor Auth; getSession() lê cookie sem verificar assinatura e permite cookie forjado (ASVS V2.1) |
| T-01-02 | Tampering | prisma/schema.prisma — monetary field | mitigate | amountCents declarado como Int (centavos); nunca Float ou Decimal. Aritmética inteira exata elimina drift de ponto flutuante |
| T-01-03 | Elevation of Privilege | middleware.ts — route protection | mitigate | Middleware global intercepta todas as rotas não-estáticas; usuários não autenticados são redirecionados para /login antes de qualquer rendering (ASVS V4.1) |
| T-01-04 | Information Disclosure | .env.local — secrets | mitigate | .env.local no .gitignore; .env.local.example commitado sem valores reais. DATABASE_URL e DIRECT_URL nunca expostos ao cliente |
| T-01-05 | Tampering | Prisma queries — SQL injection | accept | Prisma usa prepared statements parametrizados por padrão; nunca usar $queryRaw com interpolação de string. Risco residual: baixo |
| T-01-06 | Denial of Service | Supabase free tier — auto-pause | mitigate | GitHub Actions keep-alive cron job (configurado no Plano 02) faz query leve a cada 3 dias para evitar pause de 7 dias de inatividade |
| T-01-SC | Tampering | npm install — supply chain | mitigate | Todas as dependências auditadas na Package Legitimacy Audit de RESEARCH.md; versões pinadas por major (next@15, prisma@6, zod@3, date-fns@3); sem packages [ASSUMED] ou [SUS] não verificados |
